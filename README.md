# 🌱 Detecção de Pragas (Visão)

> Detecção de pragas e doenças em lavouras com visão computacional. Analisa imagens de drone e celular para diagnóstico precoce.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/deteccao-pragas/

## 📊 Resultados-chave (KPIs)
**97.2%** Precisão · **23 tipos** Pragas · **early** Antecip. · **-31%** Defensivo

## 🧠 Tecnologias de IA
Computer Vision · Deep Learning · YOLO

## ✨ O que faz
- Detecção de 23 pragas/doenças
- Análise de drone e celular
- Diagnóstico precoce
- Recomendação de manejo

## 🗄️ Fonte de dados real
[EMBRAPA + imagens drone](https://www.embrapa.br)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com EMBRAPA + imagens drone
2. **Processamento com IA** — Computer Vision · Deep Learning · YOLO
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
